# Nou grau de Física UB

Web estàtica que explica com funciona el nou grau de Física de la Universitat de Barcelona (proposta del 23/09/2026) i en fa una valoració ràpida. Disponible en català (per defecte) i castellà.

- `index.html`: tota la pàgina (text, estils i gràfics).
- `vendor/`: React 18.3.1, necessari per als gràfics interactius.
- `.nojekyll`: indica a GitHub Pages que publiqui els fitxers tal com són.

## Publicar a GitHub Pages

1. Crea un repositori públic a GitHub (per exemple, `nou-grau-fisica-ub`).
2. Puja-hi el contingut d'aquesta carpeta (*Add file › Upload files*), mantenint la carpeta `vendor/`.
3. Ves a *Settings › Pages*, tria *Deploy from a branch*, branca `main` i carpeta `/ (root)`, i desa.
4. Al cap d'un o dos minuts la web serà a `https://<el-teu-usuari>.github.io/nou-grau-fisica-ub/`.
